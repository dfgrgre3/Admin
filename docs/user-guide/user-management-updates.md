# تحديثات إدارة المستخدمين

## نظرة عامة
تم تطوير نظام إدارة مستخدمي المنصة بإضافة ميزات جديدة لتحسين التحكم في حسابات المستخدمين وتتبع الأمان.

## الميزات الجديدة

### 1. إدارة حالة المستخدم (User Status Management)
- **أنواع الحالات**: ACTIVE (نشط), SUSPENDED (موقوف), BANNED (محظور), INACTIVE (غير نشط)
- **إيقاف الحساب (Suspend)**: تعطيل وصول المستخدم للمنصة مؤقتاً مع إمكانية إلغاء الإيقاف
- **حظر المستخدم (Ban)**: منع المستخدم نهائياً من الوصول إلى المنصة
- **إلغاء الحظر/الإيقاف**: استعادة وصول المستخدم بضغطة زر

### 2. تبويب الأمان (Security Tab)
- **إدارة الحالة**: أزرار سريعة للإيقاف والحظر مع تأكيد مزدوج
- **سجل الأمان**: عرض جميع الأحداث الأمنية المتعلقة بالمستخدم
- **بحث في السجل**: إمكانية البحث والتصفية في سجل الأمان
- **تحديث مباشر**: زر لتحديث سجل الأمان
- **أيقونات ملونة**: تمييز أنواع الأحداث بألوان وأيقونات مختلفة

### 3. تحسينات الشريط الجانبي
- **عرض حالة المستخدم**: إظهار شارة حالة المستخدم (موقوف/محظور) بجانب الدور
- **زر الأمان**: إضافة زر "الأمان والحظر" في الإجراءات السريعة

## كيفية الاستخدام

### إيقاف حساب مستخدم:
1. انتقل إلى صفحة تفاصيل المستخدم
2. اختر تبويب **الأمان**
3. اضغط على **إيقاف الحساب**
4. أكد الإجراء في نافذة التأكيد

### حظر مستخدم:
1. اتبع نفس الخطوات أعلاه
2. اضغط على **حظر المستخدم**
3. أكد الحظر (ملاحظة: هذا الإجراء نهائي)

### عرض سجل الأمان:
1. في تبويب **الأمان**، سيظهر سجل الأمان تلقائياً
2. استخدم حقل البحث لتصفية الأحداث
3. اضغط على **تحديث** لجلب أحدث الأحداث

## متطلبات الواجهة الخلفية
- يجب أن تدعم API نقطة `PATCH /admin/users/:id` حقل `status`
- يجب أن توفر نقطة `GET /admin/security/logs/users/:id` سجل الأمان
- يجب أن يحتوي `User` model على حقل `status` من نوع string
